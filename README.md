# osiris-deb-repo

Signed APT repository for the [OSIRIS theme](https://github.com/richardblaha/osiris-theme),
served by GitHub Pages at <https://richardblaha.github.io/osiris-deb-repo/>.

Contents are generated and pushed by `osiris-theme`'s release workflow — do not edit by hand.

```sh
curl -fsSL https://richardblaha.github.io/osiris-deb-repo/setup.sh | sudo sh
sudo apt install osiris-desktop-theme
```
