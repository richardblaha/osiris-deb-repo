OSIRIS APT repository

Debian/Ubuntu packages for the OSIRIS desktop theme — GTK/GNOME, KDE Plasma, the Material Symbols Rounded icon theme, the GRUB theme and the wallpapers. Packages are architecture-independent, so this works on any apt-based distribution.

Quick add

curl -fsSL https://richardblaha.github.io/osiris-deb-repo/setup.sh | sudo sh

Or install osiris-archive-keyring from the latest release — it adds this repository and its key, so updates arrive via apt upgrade.

Manual

curl -fsSL https://richardblaha.github.io/osiris-deb-repo/osiris-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/osiris-archive-keyring.gpg > /dev/null
curl -fsSL https://richardblaha.github.io/osiris-deb-repo/osiris.sources \
  | sudo tee /etc/apt/sources.list.d/osiris.sources > /dev/null
sudo apt update
sudo apt install osiris-desktop-theme

Suite stable, component main. Key fingerprint is shown in osiris-archive-keyring.asc. Built from OSIRIS 0.2.0.
